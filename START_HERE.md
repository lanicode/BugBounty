# Start here

Dieses Paket kombiniert:

- den Architektur-Blueprint im Repository-Root,
- den alten Demo-MVP unter `legacy/mvp/`,
- den vollständigen Codex-Auftrag in `CODEX_STARTPROMPT.md`.

## Minimaler Ablauf

1. Erstelle ein **privates** Git-Repository aus diesem Ordner.
2. Öffne das Repository in Codex App, Codex CLI oder der Codex-IDE-Erweiterung.
3. Erstelle einen neuen Branch beziehungsweise Worktree.
4. Kopiere den gesamten Inhalt von `CODEX_STARTPROMPT.md` in die erste Codex-Aufgabe.
5. Prüfe nach Abschluss den Diff und die von Codex gemeldeten Testergebnisse, bevor du irgendetwas gegen ein reales Ziel ausführst.

Der Auftrag verbietet Codex ausdrücklich, reale Bug-Bounty-Ziele oder Plattformkonten zu kontaktieren.
